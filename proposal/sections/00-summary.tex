\subsection*{Abstract}
This proposal presents EventLens, a research system that tests whether prediction-market activity can improve event-driven risk analysis for major US indices and selected index-tracking exchange-traded funds (ETFs). Polymarket, a prediction market, provides market-implied event probabilities as prices, while on-chain settlement records link activity to wallet addresses. EventLens combines these sources to estimate experimental wallet-informed probabilities.

The study first compares market and wallet-informed probabilities on historical events. It then tests whether prediction-market features improve volatility forecasts against a recent-return baseline. Subject to data availability, an extension will test whether reviewed related-event features and agent-assisted event selection add incremental out-of-sample value.

EventLens presents the analysis through a dashboard and a controlled artificial-intelligence assistant. Users can compare probability estimates, inspect supporting wallet evidence, explore portfolio scenarios and receive explanations linked to versioned data and model outputs.
